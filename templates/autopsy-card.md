# 策略尸检卡模板

> 适合短内容、社媒传播的精简格式

---

```
┌─────────────────────────────────────────┐
│  ⚠️ 策略尸检卡                          │
│                                         │
│  策略：{策略名称}                        │
│  市场：{预测市场/现货/合约}              │
│                                         │
│  表面 Edge：{看似能赚多少}               │
│  复刻完整度：{XX%}                       │
│  增强内容：{加入了哪些真实约束}           │
│                                         │
│  主要死因：{一句话}                      │
│  次要死因：{简述}                        │
│                                         │
│  负 Alpha 指数：★★★★☆                   │
│                                         │
│  亏钱概率：{高/中/低}                    │
│  回测欺骗性：{高/中/低}                  │
│  实盘执行难度：{高/中/低}               │
│  可改造价值：{无/低/中/高}               │
│                                         │
│  最终判定：                              │
│  {完全死亡/半死不活/不能裸用/            │
│   可改造成模块/小样本存活}               │
│                                         │
│  实验编号：BAL-XXX                       │
└─────────────────────────────────────────┘
```

## 示例

```
┌─────────────────────────────────────────┐
│  ⚠️ 策略尸检卡                          │
│                                         │
│  策略：YES/NO 补数套利                   │
│  市场：预测市场                          │
│                                         │
│  表面 Edge：+3-5% "无风险套利"           │
│  复刻完整度：85%                         │
│  增强内容：加入手续费、深度限制、         │
│  成交概率、撤单延迟                      │
│                                         │
│  主要死因：partial fill 暴露单边风险     │
│  次要死因：手续费吃掉价差、               │
│  tick size 导致精度损失                  │
│                                         │
│  负 Alpha 指数：★★★★☆                   │
│                                         │
│  亏钱概率：高                            │
│  回测欺骗性：高                          │
│  实盘执行难度：高                        │
│  可改造价值：中                          │
│                                         │
│  最终判定：不能裸用                      │
│  → 可转化为 consistency checker 模块     │
│                                         │
│  实验编号：BAL-001                       │
└─────────────────────────────────────────┘
```
