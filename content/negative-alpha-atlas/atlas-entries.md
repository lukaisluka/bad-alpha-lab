## ATL-001: 套利策略的 Alpha 消亡路径

**策略类型：** YES/NO 补数套利
**涉及报告：** BAL-001, AUT-001, AUT-002

### Alpha 消亡流程图

```
理论 Alpha                          实际 Alpha
─────────                          ─────────
                                   
   +5%                               -2%
    │                                 │
    │  ┌──────────────┐               │
    │  │  理论价差 5%  │               │
    │  │ YES+NO=0.95  │               │
    │  └──────────────┘               │
    │         │                       │
    │         ▼                       │
    │  ┌──────────────┐               │
    │  │ Ask价格调整   │    -2%       │
    │  │ 实际价差3%    │ ────────→    │
    │  └──────────────┘               │
    │         │                       │
    │         ▼                       │
    │  ┌──────────────┐               │
    │  │ 手续费扣除    │    -1.9%     │
    │  │ 3%→1.1%      │ ────────→    │
    │  └──────────────┘               │
    │         │                       │
    │         ▼                       │
    │  ┌──────────────┐               │
    │  │ Partial Fill │    -3%       │
    │  │ 单边风险      │ ────────→    │
    │  └──────────────┘               │
    │                                 │
    ▼                                 ▼
  理论 +5%                         实际 -2%
```

### 消亡节点详解

| 节点 | 理论值 | 损耗 | 损耗原因 |
|------|--------|------|---------|
| 理论价差 | 5% | 0% | 初始假设 |
| Ask 价格调整 | 3% | -2% | 你看到的价格≠你能成交的价格 |
| 手续费扣除 | 1.1% | -1.9% | 双边各扣一次手续费 |
| Partial Fill | -2% | -3.1% | 只成交一边变成单边赌博 |

**结论：** 每 5% 的理论价差，实际亏损约 2%。Alpha 在每个执行节点都在衰减。

## ATL-002: 做市商策略的 Alpha 消亡路径

**策略类型：** Spread capture 做市商
**涉及报告：** BAL-003, AUT-003

### Alpha 消亡流程图

```
理论 Alpha                          实际 Alpha
─────────                          ─────────
                                   
   +4%                               -6%
    │                                 │
    │  ┌──────────────┐               │
    │  │  Spread 4%   │               │
    │  │  bid-ask差   │               │
    │  └──────────────┘               │
    │         │                       │
    │         ▼                       │
    │  ┌──────────────┐               │
    │  │ Adverse      │    -2%       │
    │  │ Selection    │ ────────→    │
    │  └──────────────┘               │
    │         │                       │
    │         ▼                       │
    │  ┌──────────────┐               │
    │  │ Inventory    │    -4%       │
    │  │ Risk         │ ────────→    │
    │  └──────────────┘               │
    │         │                       │
    │         ▼                       │
    │  ┌──────────────┐               │
    │  │ Spread压缩   │    -2%       │
    │  │ (竞争)       │ ────────→    │
    │  └──────────────┘               │
    │                                 │
    ▼                                 ▼
  理论 +4%                         实际 -6%
```

### 消亡节点详解

| 节点 | 理论值 | 损耗 | 损耗原因 |
|------|--------|------|---------|
| Spread | 4% | 0% | 初始假设 |
| Adverse Selection | 2% | -2% | 知情交易者吃掉你的报价 |
| Inventory Risk | -2% | -4% | 持仓方向亏损 |
| Spread 压缩 | -6% | -2% | 竞争做市商压缩利润空间 |

**结论：** Spread 是"看的见的收入"，inventory 和 adverse selection 是"看不见的亏损"。看不见的远大于看得见的。

## ATL-005: 策略生命周期 Alpha 曲线

**策略类型：** 通用策略生命周期模型
**涉及报告：** 所有报告的综合

### Alpha 生命周期曲线

```
Alpha %
  │
  │     ┌──┐
  │    /    \        ← 发现期：Alpha 看起来很高
  │   /      \
  │  /        \      ← 传播期：更多人知道，Alpha 开始衰减
  │ /          \
  │/            \    ← 竞争期：竞争者涌入，Alpha 快速归零
  │              \   
  │               \  ← 衰亡期：Alpha 变负，策略稳定亏损
  │                ────────────
  │
  └──────────────────────→ 时间
     发现  传播  竞争  衰亡
```

### 生命周期各阶段

| 阶段 | Alpha | 参与者 | 特征 |
|------|-------|--------|------|
| 发现期 | +20~50% | 1~5人 | 策略刚被发现，edge 最大 |
| 传播期 | +5~20% | 5~50人 | 策略被公开讨论，edge 开始衰减 |
| 竞争期 | 0~5% | 50~500人 | 大量竞争者，edge 几乎归零 |
| 衰亡期 | -5~20% | 500+人 | edge 为负，新手继续涌入 |

**关键洞察：** 策略的 Alpha 和参与人数成反比。你看到策略时，通常已经到了传播期或竞争期。到衰亡期时，社交媒体上的推荐最多。

### 消亡加速器

1. **社交媒体传播** — 一条推文可以让策略从发现期跳到竞争期
2. **自动化工具** — 跟单 bot、做市 bot 让参与门槛更低
3. **教程和课程** — "策略教程"通常教的是衰亡期的策略
4. **回测工具** — 让更多人能"验证"已经失效的策略
