# 策略验尸报告

> Autopsy Reports — 拆解策略的死因

---

## AUT-001: Partial Fill 综合征

**死因分类：** 执行风险
**涉及策略：** BAL-001 (YES/NO套利), BAL-003 (做市商)
**负 Alpha 评级：** ★★★★☆

### 尸体描述

策略在回测中完美运行，双边同时成交，利润确定。实盘中，只有一边成交，"无风险套利"变成单边赌博。

### 死因解剖

**表面死因：** 订单没有同时成交

**真正死因：** 预测市场的成交机制不支持"原子性双边成交"

在传统金融中，你可以用 IOC（Immediate or Cancel）订单确保双边要么同时成交，要么同时取消。但在 Polymarket 上：

1. 你先下 YES 单，等待成交
2. YES 单成交了
3. 你下 NO 单，但价格已经变了
4. NO 单成交不了，或者成交价更差

**这不是 bug，是结构性的。** Polymarket 的 CLOB 不支持跨市场原子订单。你永远无法保证双边同时成交。

### 亏损路径

```
理想路径：买YES + 买NO → 结算 → 赚价差
实际路径：买YES → NO价格变了 → 只持YES → 结算 → 可能大亏
```

### 验尸结论

Partial fill 不是"偶尔发生的小问题"，而是预测市场套利策略的结构性缺陷。任何依赖"双边同时成交"的策略，在 Polymarket 上都有这个致命伤。

**同类死因策略：** 所有跨合约套利、做市商的 round trip 假设

## AUT-002: 手续费黑洞

**死因分类：** 成本侵蚀
**涉及策略：** BAL-001 (YES/NO套利), BAL-003 (做市商)
**负 Alpha 评级：** ★★★☆☆

### 尸体描述

策略的表面利润（spread/价差）看起来可观，但扣除手续费后变成亏损。

### 死因解剖

**表面死因：** 手续费太高

**真正死因：** 策略的利润来源（spread/价差）太小，无法覆盖交易成本

数学：
- 价差 = 3%
- 手续费 = 2% × 2次 = 4%（双边各一次）
- 净利润 = 3% - 4% = -1%

**关键洞察：** 手续费不是"额外成本"，而是策略利润的"天花板"。当你的利润来源是 3-5% 的价差时，2% 的手续费就是致命的。

### 亏损路径

```
理想：价差3% → 赚3%
实际：价差3% - 手续费4% → 亏1%
更实际：价差3% - 手续费4% - 滑点1% → 亏2%
```

### 验尸结论

任何利润来源是"小价差"的策略，在预测市场中都面临手续费黑洞。这不是手续费"太高"的问题，而是策略的 edge 太薄。

**同类死因策略：** 所有 spread-based 策略、高频做市

## AUT-003: Adverse Selection 陷阱

**死因分类：** 信息不对称
**涉及策略：** BAL-003 (做市商), BAL-004 (跟单)
**负 Alpha 评级：** ★★★★★

### 尸体描述

策略提供流动性或跟单，但对手方总是"知道得更多"。每次成交都是亏钱的。

### 死因解剖

**表面死因：** 对手方太聪明

**真正死因：** 预测市场的交易主要是信息驱动的，不是流动性驱动的

在传统市场中：
- 70% 的交易是流动性驱动的（随机、无方向）
- 30% 的交易是信息驱动的（有方向、有观点）

在预测市场中：
- 30% 的交易是流动性驱动的
- 70% 的交易是信息驱动的

**这意味着：** 在预测市场中做市，你 70% 的成交对手是知情交易者。你每提供 1 份流动性，就有 0.7 份是在和比你聪明的人交易。

### 亏损路径

```
做市商挂单 → 知情交易者成交 → 价格移动 → 做市商亏损
跟单者买入 → 大户已经获利了结 → 价格回落 → 跟单者亏损
```

### 验尸结论

Adverse selection 是预测市场中最致命的风险。它不是"可以管理"的风险，而是"结构性存在"的风险。预测市场的本质就是信息交易，做市商和跟单者天然处于信息劣势。

**同类死因策略：** 所有提供流动性的策略、所有依赖他人交易的策略

## AUT-004: 幸存者偏差幻觉

**死因分类：** 统计陷阱
**涉及策略：** BAL-004 (跟单)
**负 Alpha 评级：** ★★★★☆

### 尸体描述

"过去赚钱的大户"在未来不再赚钱，跟单者亏损。

### 死因解剖

**表面死因：** 大户变笨了

**真正死因：** 大户从来没有"聪明"过，他们只是"幸运"过

1000 个随机交易者中，3 个月后纯靠运气会有约 50 个盈利。这 50 个人就是"聪明钱"。但他们的未来表现和随机交易者没有区别。

**更隐蔽的版本：**
- 你选择"过去 30 天盈利 top 10"的大户
- 但 30 天的样本太小，无法区分运气和能力
- 即使 1 年的样本，在预测市场这种高波动环境中也不够

### 亏损路径

```
选择过去赚钱的大户 → 跟单 → 大户回归均值 → 跟单者亏损
```

### 验尸结论

幸存者偏差是跟单策略的根基性缺陷。你无法从历史数据中区分"聪明"和"幸运"，这意味着跟单策略的信号源本身就是不可靠的。

**同类死因策略：** 所有基于历史排名的策略、所有"跟着赢家走"的策略

## AUT-005: 延迟侵蚀

**死因分类：** 执行风险
**涉及策略：** BAL-004 (跟单), BAL-003 (做市商)
**负 Alpha 评级：** ★★★☆☆

### 尸体描述

策略信号正确，但执行延迟导致买入价更高、卖出价更低，利润被侵蚀。

### 死因解剖

**表面死因：** 系统太慢

**真正死因：** 信息在传播过程中已经被价格反映

从大户交易到跟单者执行，存在不可避免的延迟：
- 区块确认：5-15秒
- 检测系统：10-30秒
- 决策+下单：5-30秒
- 总延迟：20秒-2分钟

在这段时间内，价格已经移动了。你买到的价格，已经不是大户买到的价格。

**延迟不对称：**
- 大户在 0.50 买入，你在 0.55 跟入
- 如果价格到 0.60：大户赚 20%，你赚 9%
- 如果价格回到 0.50：大户不亏，你亏 9%

### 验尸结论

延迟不是"可以优化"的技术问题，而是跟单策略的结构性劣势。你永远比信号源慢，这意味着你的利润永远比信号源少，亏损永远比信号源多。

**同类死因策略：** 所有依赖他人交易信号的策略
